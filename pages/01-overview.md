# Headless agents: why I use this setup

I want my agent chats to keep running when I close the laptop. So the chats and project files live on a Linux VM, with Herdr keeping their terminal panes together. The laptop is where I see and steer them.

A Mac or Ubuntu desktop connects through SSH. Jarvis adds a quick command window, local speech and a paste box. The VM keeps the decisions in one place; the desktop handles the microphone and display.

You bring your own VM, accounts and SSH keys. The kit contains placeholders rather than anyone else's credentials, files or chats. Start with the terminal setup in README, then add voice once reconnecting works.

This is a small, clean starter. It gives you the structure and core controls; the richer personal artwork, wake-word integration and automatic project routing are separate extensions. The five Pages can be pasted into a shared Space, with the ZIP stored in your own Drive when you're ready.
