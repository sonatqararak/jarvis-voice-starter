What is real in this demo?

The shortened spoken quote and tracker rebuild come from the 29 Sep case study. The tracker refreshed every 20 seconds; completion at 02:57 was reported by the agent the next morning. Opening agent-built pages is a separate logged capability. This is a reconstruction combining those capabilities, not a recording of one complete interaction. The final opening phrase is illustrative. The orb is adapted from the original Nebula tide design.

Speech recognition runs locally in the documented setup. Some interpretation and summaries use cloud models. Replies are text. Mac desktop actions use Hammerspoon; Ubuntu support is early. System One is a separate tool. Jev checks potentially outward-facing send/pay intent. Its assisted routing has only been smoke-tested. No Jev intervention is evidenced in this tracker episode.
